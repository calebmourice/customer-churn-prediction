# Customer Churn Prediction Using Machine Learning

A data science project that uses Python and machine learning to predict customer churn and estimate the likelihood that a customer will leave a service.

## Project Overview

Customer churn is a major challenge for businesses that rely on retaining customers. Predicting which customers are likely to leave can help organizations make informed decisions, improve customer retention, and develop targeted engagement strategies.

This project explores customer churn prediction using Logistic Regression.

## Objectives

- Explore and prepare customer data for machine learning.
- Build a Logistic Regression classification model.
- Predict whether a customer is likely to churn.
- Estimate the probability of customer churn.
- Evaluate model performance and identify opportunities for improvement.

## Machine Learning Approach

The project uses Logistic Regression, a supervised machine learning algorithm for binary classification.

The model estimates the probability of churn and classifies customers into categories such as:

- **Churn: Yes**
- **Churn: No**

The probability estimate can help identify customers who may need additional attention.
